# ลอยกระทง Live

เกมลอยกระทงแอนิเมชันสำหรับไลฟ์ TikTok: ผู้ชมคอมเมนต์เลือกชาย/หญิง ส่งของขวัญเพื่อเปลี่ยนเป็นกระทงที่ใหญ่ขึ้น ตัวละครเดินไปลอยกระทงที่ท่าน้ำ

## เริ่มใช้งาน (โหมดเดโม)

```bash
npm install
npm start
```

| หน้า | ที่อยู่ | ใช้ทำอะไร |
|---|---|---|
| หน้าเกม | http://127.0.0.1:3030/game/ | ใส่ใน OBS / เปิดดู (`?debug=1` มีปุ่มทดสอบ, `?mode=landscape` แนวนอน) |
| แผงควบคุม | http://127.0.0.1:3030/admin/ | มอนิเตอร์สถานะ ทดสอบของขวัญ สลับโหมด |
| สถานะ (JSON) | http://127.0.0.1:3030/api/health | ให้เครื่องมืออื่นตรวจสุขภาพระบบ |

## ไลฟ์จริง

1. ตั้งค่าตัวแปร (หรือกรอกในแผงควบคุมได้เลย)
   ```powershell
   $env:MODE="live"; $env:TIKTOK_USERNAME="ชื่อช่อง"; npm start
   ```
2. OBS: เพิ่ม **Browser Source** ที่ `http://127.0.0.1:3030/game/` ขนาด **1080×1920** (ตั้ง Canvas OBS เป็น 1080×1920)
3. สตรีมเข้า TikTok ผ่าน TikTok LIVE Studio หรือ Stream Key

> ตัวเชื่อม `tiktok-live-connector` ไม่ใช่ API ทางการของ TikTok อาจใช้ไม่ได้หลัง TikTok อัปเดต ระบบจะเชื่อมต่อใหม่อัตโนมัติและแจ้งเตือนในแผงควบคุม ควรทดสอบไลฟ์สั้น ๆ ก่อนใช้งานจริงเสมอ

## ตัวแปรสภาพแวดล้อม

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `MODE` | `demo` | `demo` หรือ `live` |
| `TIKTOK_USERNAME` | – | ชื่อช่องที่ไลฟ์ |
| `PORT` / `HOST` | `3030` / `127.0.0.1` | ที่อยู่เซิร์ฟเวอร์ |
| `ADMIN_TOKEN` | – | ถ้าตั้ง ต้องใส่ token ในหน้า Admin (`/admin/?token=...`) |
| `DEMO_AUTOPLAY` | `true` | สร้างผู้ชมจำลองอัตโนมัติ |

ปรับระดับกระทง เกณฑ์เพชร เปอร์เซ็นต์ทำบุญ ได้ที่ `config/gifts.json` (กด "โหลด config ใหม่" ในแผงควบคุม)

## โครงสร้างโปรเจกต์

```
config/gifts.json          ระดับกระทง/เกณฑ์/คำเลือกเพศ
server/
  index.js                 จุดเริ่มต้น
  config.js                ค่าตั้งต้นจาก env
  core/                    logger, metrics, health (แจ้งเตือน), ledger (บัญชี), pipeline (event → งาน), gifts, status
  sources/                 demo-source, tiktok-source, manager (สลับโหมด)
  net/                     hub (WebSocket), api (REST)
public/
  game/js/                 engine, scene/ (ฉาก), actors/ (ตัวละคร/กระทง), fx/ (เอฟเฟกต์), ui/, core/
  game/css/                game.css, hud.css
  admin/                   แผงควบคุม (api, render, controls)
data/ledger.json           บัญชีของขวัญ (สร้างอัตโนมัติ)
```

## การไหลของข้อมูล

```
TikTok/Demo → source → bus('event') → pipeline → bus('job') → hub → หน้าเกม (คิว → ตัวละคร → กระทง)
                                  └→ metrics / ledger / health → แผงควบคุม (WebSocket)
```

## ระบบมอนิเตอร์

เซิร์ฟเวอร์ตรวจทุก 2 วินาที: ตัวเชื่อมต่อ, จำนวนจอเกมและ FPS (หน้าเกมส่ง heartbeat ทุก 3 วินาที), คิวค้าง, หน่วยความจำ, และความเงียบผิดปกติในไลฟ์จริง มีการเปิด/ปิดการแจ้งเตือนอัตโนมัติ ข้อผิดพลาดจากเบราว์เซอร์ถูกส่งกลับมาเก็บใน log

## เรื่องเงินทำบุญ

ระบบบันทึกของขวัญจริงลง `data/ledger.json` และออกรายงาน CSV ได้ ตัวเลขบาทเป็นประมาณการเท่านั้น ควรเผยแพร่หลักฐานการทำบุญและสัดส่วนที่ชัดเจนต่อผู้ชม ไม่อ้างผลศักดิ์สิทธิ์จากการส่งของขวัญ
